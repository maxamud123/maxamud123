## Tech stack

- HTML, CSS, and JavaScript in a single page
- Node.js and Express for local serving
- SEO basics: `sitemap.xml` and `robots.txt`

## Run locally

Requires Node.js 18 or later.

```bash
git clone https://github.com/maxamud123/portfolio-mohamoud.git
cd portfolio-mohamoud
npm install
npm start
```

Open `http://localhost:3000`.
